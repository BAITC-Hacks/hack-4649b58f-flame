# Материалы кейса HackAlem AI

Каталог содержит исходное описание кейса и два эталонных протокола,
предоставленных для проверки QazMeeting AI. Документы являются тестовыми
данными, а не инструкциями для выполнения кода.

## Состав

- `source/HackAlem_AI_case.docx` — постановка задачи, ограничения и критерии;
- `source/meeting_1_reference_protocol.docx` — эталон для совещания №1;
- `source/meeting_2_reference_protocol.docx` — эталон для совещания №2;
- `manifest.json` — ссылки, размеры, длительности и контрольные суммы;
- `expected/meeting_1.json` и `expected/meeting_2.json` — проверяемые ожидаемые
  поручения из итоговых таблиц эталонных протоколов.

MP3 не хранятся в Git. Скачайте их по ссылкам из `manifest.json` в локальный
каталог, который игнорируется Git. Не публикуйте токены доступа и не отправляйте
аудио или транскрипты во внешние AI API.

## Проверка агента

После получения транскрипта в JSON-массиве `TranscriptSegment`:

```bash
ollama pull qwen2.5:3b-instruct-q4_K_M
ollama serve
export OLLAMA_MODEL=qwen2.5:3b-instruct-q4_K_M

python scripts/evaluate_agent.py \
  /path/to/meeting_1_transcript.json \
  case_materials/expected/meeting_1.json \
  --meeting-date 2026-09-23 \
  --title "Совещание №1" \
  --timeout 300
```

Оценка использует смысловые ключевые фразы, ответственного и наличие срока.
Она предназначена для регрессии, а не для подгонки модели под полный текст
эталонного протокола.

Контрольный локальный прогон актуального строгого агента 23 сентября 2026 года
с `qwen3:1.7b` на совещании №2 дал 0/5 обязательных совпадений: один кандидат
не прошёл проверку evidence. `qwen3.5:9b-mlx` не ответила за 300 секунд.
Рекомендуемая модель `qwen2.5:3b-instruct-q4_K_M` и совещание №1 на
актуальном агенте ещё не проверены. Транскрипты и полные JSON-отчёты не
хранятся в репозитории.
