QazMeeting AI — запуск интерфейса
================================

1. Откройте PowerShell в корне репозитория.

2. Убедитесь, что используется Python 3.11:
   .\.venv\Scripts\python.exe --version

3. Запустите Streamlit:
   .\.venv\Scripts\python.exe -m streamlit run streamlit_app.py

4. Откройте в браузере:
   http://localhost:8501

Для проверки интерфейса без аудиомодуля выберите «Демо интерфейса» и нажмите
«Открыть демонстрационный протокол».

Для настоящей обработки выберите «Локальная обработка аудио», загрузите MP3/WAV
и нажмите «Начать локальную обработку». Аудио и транскрипт обрабатываются локально.

Остановка приложения: нажмите Ctrl+C в окне PowerShell.
